# 百工·剪：界面与工作区规划

## 设计目标与边界

剪是围绕时间线工作的非线性视频编辑器。视觉参考百工·锻：浅青灰背景、绿色强调色、半透明毛玻璃容器、细边框与柔和圆角。信息架构独立按剪辑流程设计，不沿用图像编辑器的图层中心布局。

本轮只调整前端界面和工作区组织，不修改冶、媒体处理、播放或导出算法。现有能力保留；下文标为“规划”的能力不代表已经实现，不以虚假进度或模拟媒体结果冒充完成。

## 主工作区

默认布局：左侧项目素材 → 中间节目预览 → 右侧检查器；底部时间线横贯整个工作区。顶部放应用菜单和当前工具选项，导出入口收进文件菜单，底部状态栏反馈操作状态。

常用“小窗口”是主窗口内的停靠面板；只有短暂、需要确认的操作使用对话框。首轮不引入独立操作系统浮动窗口，避免焦点、窗口遮挡和多屏位置恢复的复杂度。

| 面板 | 作用与内容 | 与其他面板的关系 | 本轮状态 |
| --- | --- | --- | --- |
| 项目素材 | 收集原始视频、音频和图片；显示缩略图、名称和媒体信息 | 现有双击插入时间线行为保留；后续加入文件夹、搜索、筛选与列表视图 | 独立常驻左侧；现有导入能力保留 |
| 节目预览 | 查看当前序列在播放头位置的合成画面；播放、定位、画布缩放与变换 | 跟随时间线播放头；选中片段与右侧属性联动 | 常驻中间，使用现有预览 |
| 时间线 | 安排片段顺序、时长与轨道；选择、分割、移动、裁切 | 是编辑状态的主要来源；选中片段驱动检查器 | 底部贯穿，保留已有操作和高度调节 |
| 片段属性 | 查看所选片段，并调整已有变换、透明度、音量等参数 | 无选择时显示序列信息；多选时明确提示，未来才开放批量属性 | 右侧默认页，复用现有控件 |
| 轨道管理 | 集中查看视频/音频轨道、片段以及锁定、静音、独奏状态 | 与时间线使用同一份状态；选片段后切回属性 | 右侧第二页，替代“图层”定位 |
| 素材源预览 | 在加入序列前单独检查原始素材、选择入点和出点 | 与节目预览区分；不得改变序列播放头；支持插入/覆盖 | 规划，等待独立源预览能力 |
| 效果与转场库 | 按分类查找效果、收藏、应用到片段或剪辑点 | 应用后在检查器管理参数与顺序；不在库中编辑参数 | 规划，不摆放无效可用按钮 |
| 字幕与文字 | 管理字幕列表、时间范围、样式及安全区 | 与字幕轨道及节目预览联动 | 规划，不承诺自动识别能力 |
| 调色 | 基础曝光、对比度、白平衡及后续色轮 | 针对所选视频片段；专业示波器按需展开 | 规划，参数须有真实处理能力后开放 |
| 音频混音 | 轨道推子、声像、静音、独奏及电平表 | 与片段音量区分；电平必须来自真实音频数据 | 规划；现有静音/独奏仍由轨道管理提供 |
| 关键帧 | 查看属性随时间的变化与插值 | 与片段属性、时间线选区联动 | 规划；现有关键帧数据仅保留，不伪装可编辑 |
| 任务与消息 | 汇总导入、代理、导出任务及可恢复错误 | 状态栏显示摘要，点击查看详情 | 规划；本轮保留已有错误与导出提示 |

## 交互规则

1. 默认只展示完成粗剪所需的素材、节目预览、时间线、检查器。效果、字幕、调色、混音按任务打开，避免初始工作区堆满窗口。
2. 素材选择与时间线片段选择应是两种状态。未来的素材源预览使用独立播放控制；不得因浏览素材而覆盖当前序列预览的编辑状态。
3. 片段选中后检查器显示它的属性；锁定轨道禁止编辑。轨道管理与时间线互相反映状态，不复制另一套轨道数据。
4. 本轮保留右侧宽度和时间线高度调节。后续增加面板显示开关、布局持久化、重置布局；再考虑自定义停靠和多屏浮窗。
5. 后续窄窗口优先折叠右侧检查器，再将素材改为抽屉；不能缩小时间线到不可操作。当前先覆盖常见桌面窗口尺寸，不宣称移动端适配。
6. 不可用能力必须注明原因或不提供入口；对话框支持 Escape 取消、焦点管理与键盘操作。长任务非模态反馈，不阻塞浏览工作区。

## 视觉规范

- 外壳使用青灰与淡紫的低饱和环境渐变，面板以半透明白色叠加 28px 模糊；绿色表示主要动作与选中状态。
- 毛玻璃用于外壳和停靠面板，不给视频画面叠加滤镜，不改变媒体颜色。时间线片段靠类别颜色与标签区分，选中再加明显边框。
- 大面板圆角 14–16px，按钮 7–8px；控件保留明确边界，避免透明叠加影响读数。
- 只将深阴影用于浮层；常驻面板采用轻阴影。遵守系统减少动态效果与减少透明度偏好。
- 毛玻璃配色、面板模糊、原生透明底色与降级策略统一来自坊 `0.1.1` 的 `glass` / `glass.css` 入口。macOS 配置 Liquid Glass / sidebar 原生窗口材质；应用只保留布局、token 映射和窗口适配。

## 落地顺序

1. **本轮：** 工作区重排、锻同系浅色毛玻璃、独立素材面板、贯穿时间线、属性/轨道检查器；保留已有操作，验证构建与现有测试。
2. **下一轮界面：** 素材搜索与分类、面板折叠及布局保存、项目/序列/导出设置窗口的详细交互。尚无后端能力的选项须明确不可用。
3. **后续能力配套：** 源预览、字幕、效果、调色、混音、关键帧与任务中心。分别定义状态、错误和交互契约后再接真实能力，媒体处理接入另行开展。
