  测量与滚动监听从未挂上，刻度冻结在初始窗口（写死的 1200px≈12s）。修复：滚动容器改
  回调 ref→state、以元素实例传 TimeRuler（effect 依赖元素）；窗口刻度数学抽为
  visibleRangeUs/rulerTicks 纯函数并补测。浏览器实测：滚到 22s 处刻度正确显示 00:21–00:28。

  （首个通用控件：隐藏原生条、边缘叠加 thumb、拖拽/轨道点击、闲置淡出、onViewportChange
  交付视口元素；几何为 scrollbarGeometry 纯函数）。剪的时间线（双向）与素材池（纵向）接入；

## 二、M2：空间与编辑自由（里程碑验收：双轨叠加画布定位成片正确；全部编辑操作可撤销）

按依赖顺序施工，1→2 是核心链路，3-6 可并行。

### 1. canvas 层合成预览（core/playback）

- [ ] 预览面从「单一 video/img 元素」升级为 canvas 逐层绘制：rAF 时钟已有，每帧消费 `buildFrameDescription` 按层序（视频轨自底向上）drawImage，应用 x/y/scale/rotation/opacity 静态值。
- [ ] video/img 元素降级为解码器（不进 DOM 显示树），音频输出不变。
- 验收：两轨叠加（上层小窗/位移）预览与导出成片一致。

### 2. 画布直接操纵（features/preview）

- [ ] 选中块在预览画布上显示边框＋手柄：拖动改 transform.x/y、角柄等比 scale、旋转柄 rotation，实时写 store（微秒不动，纯 transform）。
- [ ] 数值微调入口留在 Inspector（先只读 → 本项一并开放 transform 数值编辑）。
- 验收：画布拖动后导出成片位置与预览一致。

### 3. 修剪三式与波纹（features/timeline + core/project/timelineOps）

- [ ] 边缘修剪：拖块左/右边缘改 sourceIn/sourceOut（普通模式，邻块限位）。
- [ ] 波纹修剪：修剪后后续块整体前移补空隙。
- [ ] 滚动修剪：相邻两块边界联动（此消彼长，总长不变）。
- [ ] 滑移（slip）：块不动，sourceIn/Out 在素材范围内滑动。
- [ ] 波纹删除 action（删块后移补空）。
- 验收：vitest 补齐各模式的纯函数用例（含锁定轨拒改）。

### 4. 撤销重做（core/project/store）

- [ ] 写入层快照栈：document 纯数据快照 + 动作标签，上限（如 100 步）防内存膨胀；playhead/selection 不入栈。
- [ ] `undo/redo` action ＋ Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y（fang useHotkeys），时间线与画布操作全覆盖。
- 验收：任意编辑序列可逐步撤销到底再重做，document 与最初一致（vitest 快照对拍）。

### 5. 音频基础（features/timeline + core/composite）

- [ ] 时间线块上音量线（gain Animatable 静态值拖拽调整）＋块级静音；轨道 solo 落 UI（模型已有字段）。
- [ ] WebAudio 混音底座：gain>1 放大、多源同时出声（为 M5 混音台铺路；本里程碑先保证预览听感与导出 amix 一致）。
- 验收：双音频轨叠加、静音/solo 行为与导出一致。

### 6. 长工程性能（features/timeline）

- [ ] 时间线视口虚拟化：只渲染可视区 ±缓冲的块与刻度。
- 验收：100 块工程水平滚动/缩放不掉帧（主观 60fps）。
